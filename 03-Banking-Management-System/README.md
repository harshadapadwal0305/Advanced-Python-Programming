# Banking Management System

## Aim
To develop a Banking Management System using Python and demonstrate Object-Oriented Programming concepts.

## Description
This program simulates a basic banking system. It allows users to create Savings and Current Accounts, deposit money, withdraw money, and view account details.

## Features
- Create Savings Accounts.
- Create Current Accounts.
- Deposit money.
- Withdraw money.
- Check account balance.
- View account details.
- Apply overdraft limits for Current Accounts.
- Handle invalid transactions and account details.

## Python Concepts Used
- **Classes and Objects:** Used to represent bank accounts.
- **Inheritance:** SavingsAccount and CurrentAccount inherit from BankAccount.
- **Method Overriding:** Different account types have their own withdrawal methods.
- **Encapsulation:** Account details and operations are organised within classes.
- **Exception Handling:** Handles invalid amounts, insufficient balance, and invalid account numbers.
- **Dictionaries:** Used to store multiple bank accounts.

## Technologies Used
- Python

2. Open the project folder.

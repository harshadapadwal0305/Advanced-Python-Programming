# Food Delivery System

## Aim
To develop a menu-driven Food Delivery System using Python and demonstrate Object-Oriented Programming and advanced Python concepts.

## Description
This program simulates a basic food delivery system where customers can view restaurants, select food items, place orders, and calculate their bills.

## Features
- Display available restaurants.
- View food items and their prices.
- Add food items to an order.
- Display the customer's order.
- Calculate the total bill.
- Generate an order report.

## Python Concepts Used
- **Classes and Objects:** Used to represent food items, restaurants, and customers.
- **Inheritance:** Pizza, Burger, and Beverage inherit from the FoodItem class.
- **Method Overriding:** Different food classes provide their own get_details() method.
- **Decorators:** Used to display messages before and after placing an order.
- **Iterators:** Used to display food items.
- **Generators:** Used to generate order reports.
- **Exception Handling:** Handles invalid quantities and menu choices.
- **Class Variables:** Used to maintain the total number of orders.

## Technologies Used
- Python

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Run the following command:

```bash
python FoodDeliverySys.py
```

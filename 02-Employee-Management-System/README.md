# Employee Management System

## Aim
To develop an Employee Management System using Python and demonstrate Object-Oriented Programming and advanced Python concepts.

## Description
This program manages different types of employees, including Developers, Data Scientists, and Managers. It allows users to add employees, assign tasks, display employee details, and generate task reports.

## Features
- Add Developers.
- Add Data Scientists.
- Add Managers.
- Assign tasks to employees.
- Display employee details.
- Generate task reports.
- Process and display employee tasks.

## Python Concepts Used
- **Classes and Objects:** Used to represent employees and their roles.
- **Inheritance:** Developer, DataScientist, and Manager inherit from the Employee class.
- **Polymorphism:** Different employee classes provide their own get_role_details() method.
- **Method Overriding:** Child classes override the parent class method.
- **Decorators:** Used to display messages before and after processing tasks.
- **Iterators:** Used to display employee information.
- **Generators:** Used to generate task reports.

## Technologies Used
- Python

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Run the following command:

```bash
python EmpMgntSys.py
```

# Advanced Python Programming

Welcome to my Advanced Python Programming repository!

This repository contains practical Python programs that I developed to understand and apply Object-Oriented Programming (OOP) concepts and other Python features.

The programs demonstrate how Python concepts can be used to develop simple, menu-driven management systems.

## Projects Included

### 1. Food Delivery System
A menu-driven program that simulates a basic food delivery system.

**Features:**
- Display restaurants and food items.
- Place food orders.
- Display customer orders.
- Calculate the total bill.
- Generate order reports.

**Concepts Used:** Classes, Objects, Inheritance, Method Overriding, Decorators, Iterators, Generators and Exception Handling.

### 2. Employee Management System
A program to manage different types of employees and their assigned tasks.

**Features:**
- Add Developers, Data Scientists and Managers.
- Assign tasks to employees.
- Display employee details.
- Generate task reports.
- Process employee tasks.

**Concepts Used:** Classes, Objects, Inheritance, Polymorphism, Method Overriding, Decorators, Iterators and Generators.

### 3. Banking Management System
A menu-driven program that simulates basic banking operations.

**Features:**
- Create Savings and Current Accounts.
- Deposit and withdraw money.
- View account details.
- Handle overdraft limits.
- Handle invalid transactions.

**Concepts Used:** Classes, Objects, Inheritance, Method Overriding, Encapsulation-related OOP structure, Dictionaries and Exception Handling.
